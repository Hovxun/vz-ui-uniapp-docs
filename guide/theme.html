主题 ​

如有自定义主题需要，将以下变量写在单独的文件中，并在 App.vue 中引入

默认主题 ​

完整变量查看 /uni_modules/vz-ui/styles/theme.scss 文件

scss
@forward "@/uni_modules/vz-ui/styles/theme.scss" with (
  $colors: (
    "primary": (
      base: blueviolet,
    ),
  )
);

暗黑主题 ​

完整变量查看 /uni_modules/vz-ui/styles/dark/theme.scss 文件

scss
@forward "@/uni_modules/vz-ui/styles/dark/theme.scss" with (
  $colors: (
    "primary": (
      base: teal,
    ),
  )
);
